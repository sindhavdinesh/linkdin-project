## ✨ Features

### Core Features
- 🎲 **Random Password Generation** - Cryptographically secure random passwords
- ✏️ **Custom Password Creation** - Add your own words and combine them
- 📏 **Adjustable Length** - 6 to 32 characters with slider control
- 🔠 **4 Character Types** - Uppercase, Lowercase, Numbers, Symbols
- 🛡️ **Real-time Strength Meter** - Visual feedback on password security
- 📋 **One-Click Copy** - Copy passwords to clipboard instantly
- 🌓 **Dual Mode** - Auto-genrate + Custom mode both available

### Additional Features
- ✅ **Crypto API Integration** - Secure random number generation
- ✅ **No External Dependencies** - Pure HTML/CSS/JS
- ✅ **Responsive Design** - Works on all devices
- ✅ **Toast Notifications** - User feedback for actions
- ✅ **Password Shuffling** - Ensures truly random results
