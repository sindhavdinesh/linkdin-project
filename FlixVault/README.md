## 📌 PROJECT OVERVIEW

**FlixVault** ek **complete movie dashboard** hai jo Netflix ke style mein bana hai. Isme aap:

- 🎬 Trending movies & TV shows dekh sakte ho
- 🔍 Search kar sakte ho movies/genre ke according
- ➕ Apni **personal watchlist** bana sakte ho (localStorage mein save hoti hai)
- 📱 Mobile, tablet, desktop - har jagah mast lagta hai

> 🎯 *Built without any framework - Pure Vanilla JavaScript*
