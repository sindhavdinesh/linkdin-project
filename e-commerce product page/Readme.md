# 🛒 E-commerce Product Page

A modern, responsive e-commerce product page built with HTML, CSS, and JavaScript.  
Perfect for showcasing a single product with add-to-cart functionality, image gallery, and responsive design.

## ✨ Features

- 🖼️ Product image gallery with thumbnails
- 📱 Fully responsive (mobile, tablet, desktop)
- 🛍️ Add to cart button with quantity selector
- 💰 Dynamic price update based on quantity
- ⭐ Product rating (stars)
- 📦 Product details (brand, SKU, category, tags)
- ✅ Simple and clean UI
