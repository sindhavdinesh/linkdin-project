## 📌 Project Overview

A **production-grade search component** that implements the **debouncing technique** to optimize API calls. Instead of making API requests on every keystroke (which can cause performance issues and unnecessary server load), this component waits for the user to pause typing before triggering the search.

### 🎯 Why Debouncing?
- **Without Debounce:** 10 keystrokes = 10 API calls 😱
- **With Debounce:** 10 keystrokes = 1 API call (only after final pause) 😎
