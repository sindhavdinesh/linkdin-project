## 🎯 Project Goal

Build a **professional blog UI** where blog posts are dynamically rendered from a local JavaScript data array. Users can:
- 🔍 Search posts by title, excerpt, or content
- 🏷️ Filter by category (Tech, Design, JavaScript, Productivity, Career)
- 📄 Navigate through paginated content (6 posts per page)
- 🌓 Toggle between light and dark mode (saves preference in localStorage)
- 📱 Enjoy a fully responsive layout (mobile-first design)

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Dynamic Rendering** | All posts are rendered from a JS data object – no hardcoded HTML |
| **Search with Debounce** | Optimized search input with 280ms debounce for smooth performance |
| **Category Filtering** | Filter posts by 5+ categories instantly |
| **Pagination** | Clean pagination with ellipsis for large datasets (12+ posts) |
| **Dark/Light Mode** | Theme toggle with localStorage persistence |
| **Responsive Navbar** | Sticky navbar, mobile-friendly grid layout |
| **Hero Section** | Engaging gradient hero banner |
| **Post Cards** | Modern card design with images, categories, date, and read time |
| **Stats Counter** | Real-time post count update on filter/search |
| **Smooth Scroll** | Auto-scroll to posts after pagination click |
