# ⏰ Real-Time Digital Clock Web App

A premium, real-time digital clock built using **HTML, CSS, and JavaScript**.  
This project demonstrates modern frontend development practices, clean UI design, and real-time functionality suitable for a professional portfolio.

---

## 🚀 Features

- ⏱️ Real-time clock (updates every second)
- 🔁 12-hour / 24-hour format toggle
- 🌙 Dark mode / Light mode toggle
- 📅 Current date display
- 🎯 Clean and centered UI layout
- ✨ Smooth animations on time updates
- 📱 Fully responsive (mobile, tablet, desktop)

---

## 🧠 Tech Stack

- **HTML5** — Semantic structure  
- **CSS3** — Modern UI (Flexbox, animations, responsive design)  
- **JavaScript (Vanilla JS)** — Logic, time handling, DOM updates
