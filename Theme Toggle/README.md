# 🌗 Theme Toggle App (Dark / Light Mode)

A modern and responsive Theme Toggle Web Application built using **HTML, CSS, and JavaScript**.  
This project allows users to switch between **Light Mode and Dark Mode** with smooth transitions and saves user preference using **localStorage**.

## 🔄 How It Works

1. On page load, the app checks localStorage for saved theme  
2. If found → applies the saved theme  
3. If not → defaults to Light Mode  
4. User toggles switch  
5. Theme updates instantly  
6. New theme is saved in localStorage  
7. On reload → same theme is applied
