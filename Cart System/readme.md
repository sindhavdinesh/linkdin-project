## 📋 Project Overview

A fully functional e-commerce cart system built with HTML, CSS, and JavaScript. This project demonstrates real-world shopping cart functionality including product listing, add to cart, quantity management, price calculation, coupon system, and localStorage persistence.

## 🎯 Project Goal

Build a professional cart system that allows users to:
- Browse products with images
- Add/remove items from cart
- Manage product quantities
- Calculate total price dynamically
- Apply discount coupons
- Save cart data locally
- Responsive design for all devices

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🖼️ **Product Listing** | Grid layout with product images, names, and prices |
| ➕ **Add to Cart** | One-click add products to shopping cart |
| 🔢 **Quantity Management** | Increase/decrease product quantity with +/− buttons |
| ❌ **Remove Items** | Remove individual items from cart |
| 💰 **Price Calculation** | Automatic subtotal, discount, and total calculation |
| 🎫 **Coupon System** | Apply "SAVE10" for 10% discount |
| 💾 **Local Storage** | Cart data persists after page reload |
| 📱 **Responsive Design** | Works perfectly on mobile, tablet, and desktop |
| 🛒 **Cart Sidebar** | Slide-in cart panel for better UX |
| 🔔 **Cart Badge** | Shows total items count in real-time |
