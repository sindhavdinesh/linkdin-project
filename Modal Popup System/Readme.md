## 🎯 **Project Showcase**

### 🌟 **Day 14: Modal / Popup System**

A fully reusable modal component with multiple triggers and animations.

**Features:**
- 4 different modal types (Simple, Form, Alert, Confirm)
- Smooth fade-in and slide animations
- Close via X button, overlay click, or ESC key
- Form validation and callback support
- Responsive design for all devices

**Technologies Used:**
- HTML5 semantic structure
- CSS3 with Grid, Flexbox, animations
- Vanilla JavaScript (ES6+)
- Modal class system for reusability

**Key Learnings:**
- Building reusable components
- Event delegation and handling
- Dynamic DOM manipulation
- Accessibility considerations
- State management in modals

[🔗 Github repo](https://github.com/sindhavdinesh/linkdin-project/tree/main/Modal%20Popup%20System)
