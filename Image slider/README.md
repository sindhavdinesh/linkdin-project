# 🎬 Cinematic Image Slider (Project Blood-Moon)

A premium, production-quality **Image Slider (Carousel)** built using **HTML, CSS, and Vanilla JavaScript** with a cinematic dark UI and superhero-themed visuals.

---

## 🦸 Featured Characters

This project uses high-quality cinematic wallpapers of:

* 🦇 **Batman** — The Dark Knight
* 🤖 **Iron Man** — The Tech Genius
* 🕷️ **Spider-Man** — The Friendly Hero
* 🐾 Black Panther — Wakanda Forever
* 🐜 Ant-Man — The Tiny Avenger  

These images enhance the **cinematic + “dangerous” vibe** of the UI.

## 🚀 Live Features

✨ Auto Image Slide (every 5 seconds)
✨ Pause on Hover
✨ Next / Previous Navigation
✨ Keyboard Support (← → keys)
✨ Mobile Touch Swipe
✨ Dynamic Blur Background (based on active image)
✨ Progress Bar Animation
✨ Navigation Dots (Active Indicator)
✨ Infinite Looping
✨ Fully Responsive Design

## 🧠 Flow (Step-by-Step)

1. Load superhero slide data from array
2. Render slides dynamically using JavaScript
3. Generate navigation dots
4. Show first slide by default
5. Start auto-play timer
6. Handle next/prev navigation
7. Sync dots with current slide
8. Update blurred background dynamically
9. Reset progress bar on each slide
10. Pause auto-play on hover
11. Resume on mouse leave
12. Add keyboard and touch controls
