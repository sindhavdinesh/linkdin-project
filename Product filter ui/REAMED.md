## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔍 **Live Search** | Filter products by name, description, or category as you type |
| 🏷️ **Category Chips** | Click to filter (Laptops, Audio, Cameras, Accessories, Wearables) |
| 🌗 **Dark/Light Mode** | Toggle themes with one click — preference saved in localStorage |
| 💾 **Persistent Theme** | Reload the page and your theme choice remains |
| 🖼️ **Perfect Image Fit** | `background-size: contain` — no cropping, all images visible |
| 📱 **Responsive** | Works perfectly on mobile, tablet, and desktop |
| ⭐ **Star Ratings** | Visual rating display (⭐ and ½) |
| 🧹 **One-Click Reset** | Clear all filters and search instantly |
| ⚡ **Debounced Search** | Optimized performance while typing |

**Day 10 of my 21-day JavaScript challenge!** 🎯

Today I built a **Product Filter UI** with real-time search, category filtering, and a fully functional Light/Dark mode toggle. 🌗

🔍 **What it does:**
- Live search as you type
- Filter by category (Laptops, Audio, Cameras, Accessories, Wearables)
- Toggle between Light and Dark themes (saved in localStorage)
- Responsive grid layout
- Clean product cards with perfect image sizing

⚙️ **Built with:**
HTML | CSS | Vanilla JavaScript | LocalStorage API

💡 **Key learning:**
- CSS custom properties make theme switching incredibly smooth
- Debouncing search inputs prevents unnecessary re-renders
- `background-size: contain` = perfect images every time
