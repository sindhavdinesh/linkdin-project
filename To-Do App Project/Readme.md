# 🚀 To-Do App

A modern and responsive **To-Do List Application** built using **HTML, CSS, and JavaScript**.
This project helps users manage daily tasks with a clean UI, smooth interactions, and real-time task updates.

---

# 📌 Project Overview

The To-Do App is designed to improve productivity by allowing users to:

* Add tasks
* Mark tasks as completed
* Delete tasks
* Organize daily work efficiently
* Manage tasks with a simple and user-friendly interface

This project is beginner-friendly while also demonstrating practical JavaScript DOM manipulation skills.

---

# ✨ Features

## ✅ Add Tasks

Users can quickly add new tasks to the list.

## 🗑 Delete Tasks

Remove completed or unnecessary tasks instantly.

## ✔ Mark as Complete

Tasks can be marked completed with a visual effect.

## 📱 Responsive Design

Works smoothly on:

* Mobile Devices
* Tablets
* Laptops
* Desktop Screens

## ⚡ Real-Time Updates

The UI updates instantly without page refresh.
